# v2.11.0 升级说明

## 变更
新增「装修」功能（C1：首页装修），并移除「移动端配置」菜单（其面板归并到装修下）。

## 升级步骤
1. 执行 `update.sql`（建 `diy_pages` 表 + 模板租户 diy 权限）：
   ```bash
   mysql -u<user> -p <db> < update.sql
   ```
2. 为存量租户对齐装修菜单树并移除移动端配置菜单（幂等）：
   ```bash
   php think saas:decorate-menu-reconcile
   ```

## 说明
- 侧边栏标题由前端 i18n 驱动，随前端发布生效。
- 首页装修为运行时渲染：租户在「装修/首页装修」保存并发布后，uniapp 端下次启动即生效，无需重新打包。
- 命令幂等，可重复执行。

# v2.10.1 升级说明

## 变更
租户端六个顶级菜单标题改名为 **首页 / 用户 / 应用 / 内容 / 渠道 / 系统**。

- 侧边栏标题由前端 i18n 驱动，随前端发布自动生效，无需 SQL。
- 本 `update.sql` 仅同步存量租户 `menus` 表里的 `title`，使「菜单管理」后台与种子数据一致。
- 路径、route name、组件、权限、菜单顺序均不变；无表结构变更。

## 执行
```bash
mysql -u<user> -p <db> < update.sql
```

## 说明
- 覆盖所有 tenant_id（模板 + 各租户副本）。
- 仅改 `title` 仍为旧默认值的行；租户在「菜单管理」里自定义过的标题保持不变。
- 幂等，可重复执行。

# v2.21.0 升级说明

## 变更
- 租户后台菜单：顶级「用户」改名为「会员」、「系统」改名为「设置」。
- 「设置」二级菜单重组为分组：系统设置 / 权限 / 其他（+ 保留 日志管理、消息管理 目录）。
- 「会员」二级菜单重组为分组：会员管理 / 资产记录。
- 仅改名与重组现有菜单，未新增功能页面；路由路径与权限标识不变。

## 执行
对业务库执行：
```bash
mysql -u<user> -p <dbname> < server/database/updates/v2.21.0/update.sql
```
脚本幂等，可重复执行。执行后可选：
```bash
php think saas:plugin-menu-reconcile
```

## 影响
- 面包屑层级新增一层（如「设置 / 系统设置 / 系统配置」）。
- 无数据迁移、无破坏性删除。
